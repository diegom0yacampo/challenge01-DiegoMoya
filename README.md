# challenge01-DiegoMoya
Autor: Diego Moya

Resumen del trabajo:
Este proyecto lo que he hecho es un despliegue automatizado de la infraestructura cloud utilizando Terraform para crear un bucket de Amazon S3 en AWS. Posteriormente, se configuraron los permisos de seguridad y el alojamiento estático mediante AWS CLI. Finalmente, se sincronizaron los archivos locales (HTML, CSS y JavaScript) para publicar con éxito un sitio web accesible públicamente en la nube.
